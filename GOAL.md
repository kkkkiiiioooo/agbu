# Prompt para Pesquisa Profunda (Deep Research) - AI Agent Builders & Multi-Agent Orchestration Platforms

```markdown
Faça uma pesquisa profunda exaustiva para mapear o maior número possível de plataformas, sites e aplicativos web no estilo "AI Agent Builders & Multi-Agent Orchestration Platforms" (Plataformas de Criação e Orquestração de Agentes de IA e Multi-Agentes, onde o usuário constrói, personaliza, orquestra fluxos visuais, conecta ferramentas/APIs, RAG e executa agentes autônomos ou semi-autônomos via interface web, estilo Dify, Langflow, Flowise, Stack AI, Relevance AI, Coze, Gumloop, Wordware, SmythOS, etc.).

Filtros e Regras Rígidas:
1. Critério de Inclusão: Apenas plataformas que permitam CRIAR, CUSTOMIZAR e ORQUESTRAR agentes (visualmente, via nós/canvas, low-code ou no-code) e que possuam aplicativo web / ambiente na nuvem acessível diretamente pelo navegador (pronto para usar online, mesmo que o projeto seja open source, desde que forneça versão cloud/web utilizável).
2. Critério de Exclusão:
   - Exclua provedores de infraestrutura de modelos puros ou inferência/deploy de LLMs (ex: Baseten, Replicate, Together AI).
   - Exclua plataformas que são puramente de observabilidade, métricas ou testes sem construtor de agentes (ex: AgentOps, Langfuse puro).
   - Exclua SaaS fechados que apenas "usam" IA pré-configurada de prateleira (onde você não cria nem molda o fluxo do agente).
   - Exclua bibliotecas/frameworks puramente de terminal/CLI ou código local (sem interface web na nuvem).
   - Exclua chatbots básicos sem ferramentas (tools), RAG avançado ou múltiplos passos.
3. Exaustividade: Busque em diretórios de IA, Product Hunt, lançamentos recentes, GitHub e comunidades de desenvolvedores para listar o maior número possível de ferramentas existentes no mercado (líderes, novos lançamentos e alternativas menos conhecidas).

Formato de Saída e Entrega:
- Se você tiver acesso a ambiente de execução/sistema de arquivos: salve a lista completa diretamente em um arquivo chamado `AGENT_BUILDERS.md`.
- Se você estiver em um ambiente de chat comum (sem acesso a arquivos): retorne a lista diretamente na resposta.
- O formato deve ser exclusivamente uma lista numerada direta no padrão:
  [Número]. [Nome da Ferramenta] - [URL Oficial do Web App] - [Foco Principal (máx. 4 palavras)]

Não escreva introduções, resumos, tutoriais ou conclusões. Entregue o inventário mais longo e completo possível de uma só vez.

Exemplo de formato esperado:
1. Dify.ai - https://dify.ai - LLMOps e agentes visuais
2. Langflow - https://langflow.org - Canvas visual multi-agente
3. Flowise - https://flowiseai.com - Orquestração LangChain visual
4. Stack AI - https://stack-ai.com - Workflows e automações enterprise
5. Relevance AI - https://relevanceai.com - Equipes de agentes B2B
6. Coze - https://coze.com - Bots com plugins/APIs
7. Gumloop - https://gumloop.com - Workflows e web scraping
8. MindStudio - https://mindstudio.ai - Aplicações multi-modelo no-code
9. Dust - https://dust.tt - Agentes conectados a dados
10. Voiceflow - https://voiceflow.com - Agentes conversacionais colaborativos
11. Lindy - https://lindy.ai - Agentes autônomos de produtividade
12. SuperAGI - https://superagi.com - Infraestrutura e agentes autônomos
13. Wordware - https://wordware.ai - IDE e agentes modulares
14. SmythOS - https://smythos.com - Orquestração multi-agente no-code
15. VectorShift - https://vectorshift.ai - Pipelines de IA e automação
16. Vellum - https://vellum.ai - Desenvolvimento e avaliação LLM
17. Botpress - https://botpress.com - Agentes autônomos de atendimento
18. CrewAI Enterprise - https://crewai.com - Orquestração de equipes multi-agente
```
